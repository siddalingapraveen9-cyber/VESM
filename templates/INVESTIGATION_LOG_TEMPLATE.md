# Investigation Log — Template

Stage 4. The investigation procedure itself is defined in
`ai_standard/PROBLEM_SOLVING_STRATEGY.md`; this template only records its output.
**When to Use:** Whenever behavior is unclear, unexpected, or broken, before a fix is
proposed.
**Instructions:** Fill fields in order. Do not skip Reproduction — a root cause
without reproduction steps is not yet evidenced.
