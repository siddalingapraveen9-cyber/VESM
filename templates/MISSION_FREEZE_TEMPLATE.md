# Mission Freeze — Template

**Purpose:** Record the frozen objective and scope for a development cycle, per
`core/VVBM.md` Stage 1.
**When to Use:** At the start of any development cycle, before Architecture First
begins. Re-complete (as a new, explicitly dated freeze) if the mission changes
mid-cycle.
**Instructions:** Fill every Required Field. Get explicit agreement from whoever has
authority to change the mission before marking it frozen. Do not begin Architecture
First until this document is complete and agreed.
