# Verification Report — Template

**Purpose:** Record evidence-based confirmation that a completed change matches the
frozen mission and architecture, per `core/VVBM.md` Stage 6.
**When to Use:** Before a change is considered done, and before it is submitted to
Quality Gate (`checklists/VQS_CHECKLIST.md`).
**Instructions:** One report per claim being verified. A general "it works" is not
an acceptable substitute for a specific, evidenced claim.
